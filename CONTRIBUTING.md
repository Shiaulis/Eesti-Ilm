# Contributing to Eesti Ilm

Eesti Ilm is a small iOS weather app maintained by one person. Bug reports, ideas and pull requests are welcome.

## Reporting bugs and suggesting features

Use the [issue forms](https://github.com/Shiaulis/Eesti-Ilm/issues/new/choose). Search existing issues first. For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Pull requests

- For anything larger than a small fix, open an issue first so we can agree on the approach before you spend time on it.
- Keep each pull request focused on one change.
- [AGENTS.md](AGENTS.md) is the source of truth for requirements, the build, test and format commands, conventions (Swift 6, Swift Testing, localization in English and Estonian) and the Git workflow. Run the format check, build and tests before opening the pull request.
- Pull requests follow [the pull request template](.github/pull_request_template.md).
- Open pull requests against `master`. Rebase on `master` instead of merging it into your branch.
- Do not add third-party dependencies without discussing them first.
- Never commit secrets or personal data.

The maintainer reviews and merges every pull request.
